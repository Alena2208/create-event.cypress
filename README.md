Dieses Projekt zeigt meinen Ansatz zur Automatisierung komplexer Buchungsszenarien in einem Restaurant. Das Kernstück ist die intelligente Auswahl eines Datums im Kalender.

Test-Funktionalität:

Anmeldung auf der Plattform.

Erstellung einer Veranstaltung mit schrittweiser Formularausfüllung: Auswahl des Saals, des Veranstaltungstyps, der Quelle.

Dynamische Auswahl des nächsten verfügbaren Datums (der Kalender wird analysiert, belegte Slots werden ausgeschlossen).

Eingabe von Start-/Endzeit, Gästeanzahl und Telefonnummer.

Abschließende Überprüfung der erfolgreichen Veranstaltungserstellung.
